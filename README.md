# Inside M'Kenna: 3D Body Explorer

An interactive 3D website for the OpenSciEd 7.3 Metabolic Reactions unit. Students unlock each of the 15 lessons with a code from their teacher, explore the body, ride inside organs, and run molecule and reaction labs.

Static site: `index.html` plus 3D models in `models/` (made in Blender). No build step.
